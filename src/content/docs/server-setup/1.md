如果你点开了这部分的教程，相信你一定是厌倦了原版Minecraft的孤独感，想和朋友一起体验“我们的世界”，但是我认为在决定开服之前最重要的是明确自己的需求，也就是：
> **Q1：我为什么要开服？我的需求一定要开服才能满足吗？**
> **Q2：我拥有的硬件条件满足开服的需求吗？**
本章节将围绕这两个问题进行解答，让你明白进行开服有无必要性。

# Q1 我为什么要开服？我的需求一定要开服才能满足吗？

相信这个问题你一定很疑惑：我开服不就是为了和朋友玩吗？但是有没有一种可能，如果你只和1~2名朋友玩，你其实可以通过客户端自带的**局域网联机功能**轻松实现，而不需要后文繁琐（对新手而言）的配置。
如果你认为开服只是为了展现自己多么有技术实力，或是想要体验神权的感觉，~~那我建议你退出这个教程~~。
**开服很简单，但是有人玩你的服务器却很有挑战性**， XDUCraft 为我们提供了这样的社交平台，可以让你的服务器不至于一个玩家都没有。
如果你开服的目的只是想进行技术积累，我认为这也是合理的，~~是谁暑假落幕曲一天五崩呢~~。
另一方面，明确自己的实际需求非常重要。如果你想和朋友们一起玩，除了自己开服，其实还有更轻松的选择：
1. **局域网联机**：如果你只和一到两名朋友玩，你可以通过客户端自带的**局域网联机功能**轻松实现，而不需要后文繁琐的配置。
2. **加入我们的服务器**：欢迎来到我们 XDUCraft 的公共服务器游玩（在大群中输入`-mcs`即可查看现有的服务器列表）。在这里，你也同样可以和你的朋友一起游玩，还能结识更多朋友， “独乐乐不如众乐乐”。
3. **发起你的提议**：如果你有绝妙的玩法点子，可以在大群里积极提出你的想法。如果感兴趣的人多，很可能就会有群友一起把它变成现实！
总之，明确自己的实际需求，远比开服后对着空无一人的列表发呆要好。
如果你明确自己真的需要开设一个Minecraft服务器，那么欢迎你继续向下阅读(≧∇≦)ﾉ。  

# Q2 我拥有的硬件条件满足开服的需求吗？

看到这个文档的绝大多数人应当都只拥有一台高性能设备，也就是手中的笔记本电脑，如果你想用它来开服那么至少要满足（至于配置怎么看这里不做介绍，如果你连这个都不会那么就说明你不适合开服）的要求是：
1. **处理器**应当是拥有8个核心以上的， 2021年之后推出的（Intel的第 11 代或是AMD的Ryzen5代之后）， H或HX后缀的高性能处理器。
2. **内存**尽可能大，根据经验而言：
  1. 仅开服，自己不使用电脑的话内存应当至少为16GB。
  2. 若需要在开服的同时，自己游玩或进行其他高性能任务，内存应至少为32GB。
3. 稳定的**网络**， MC服务器对带宽的要求不高，但网络的**稳定性**非常重要，这将直接影响玩家的游戏体验。因此，推荐使用有线网络连接，以尽量避免无线网络的波动与延迟。
4. 良好的**散热环境**，如果在开服阶段你的处理器温度**持续高于85℃**，建议先处理好散热问题，再进行开服或其他需要高性能的活动，过高的温度会影响到你设备的稳定性以及寿命。
5. 合适的**硬盘**：强烈建议将服务器安装在**固态硬盘**（SSD）上，这将极大改善世界加载和保存的速度。
