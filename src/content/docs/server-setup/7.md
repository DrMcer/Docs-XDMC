# 常用服务器命令


<table class="xdc-table">
<tr>
<td>命令</td>
<td>作用</td>
<td>示例</td>
</tr>
<tr>
<td>stop</td>
<td>安全地关闭服务器</td>
<td>stop</td>
</tr>
<tr>
<td>reload</td>
<td>重载服务器（**不推荐**，极易引起模组数据错乱）</td>
<td>reload</td>
</tr>
<tr>
<td>op <玩家名></td>
<td>授予玩家OP权限</td>
<td>op Steve</td>
</tr>
<tr>
<td>whitelist <add/remove> <玩家名></td>
<td>添加/移除白名单玩家</td>
<td>whitelist add CNkiran</td>
</tr>
<tr>
<td>whitelist on/off</td>
<td>开启/关闭白名单</td>
<td>whitelist on</td>
</tr>
<tr>
<td>ban <玩家名> [理由]</td>
<td>封禁一名玩家</td>
<td>ban CNkiran 太帅了</td>
</tr>
<tr>
<td>save-all</td>
<td>立即强制保存世界</td>
<td>save-all</td>
</tr>
</table>
